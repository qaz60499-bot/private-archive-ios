临时样式最终已删除并确认动画恢复，再修改产品代码。Build 14 实际安装后页面动画数为零；30 秒空闲 WebContent 0.258%（P95 0.606%），App 0.033%，GPU 进程 0.166%。因此修复有产品版本真机证据，不仅是临时 CSS 实验。仅去掉两类装饰循环；图片加载、功能性加载和重试反馈保持。

最终 Build 15 在网页检查器关闭、不带性能启动参数的正常启动下，首页 589 项，30.54 秒、30 个有效样本：WebContent 平均 0.311%／P95 3.335%／峰值 footprint 231.69 MiB；App 0.055%／0.517%／10.81 MiB；WebKit GPU 进程 0.003%／0.018%／14.14 MiB。证据为 `work/acceptance-20261021/perf15-normal-idle.json` 及同名 `-summary.json`。这再次验证正常使用入口下的空闲 CPU 改善，不能替代温度、电量或长期内存趋势测量。

## 10／30／80 项上传

每批只提交一次，完成后才开下一批。分位数统一 nearest-rank；时延来自同设备 createdAt→updatedAt，包含排队，秒精度。不能混减宿主、syslog 和设备墙钟。

| 输入 | 最终确认 | 新文件／去重 | 新文件字节 | 完成 P50 / P95 | 内容重试证据 |
| --- | --- | --- | ---: | --- | --- |
| 10 | 10/10 | 2 / 8 | 635,595 | 3 / 8 秒（含去重） | 新文件 0 次 |
| 30 | 30/30 | 30 / 0 | 33,711,101 | 36 / 57 秒 | 3 次已证实；另 1 项 attempts=2 原因未知 |
| 80 | 80/80 | 80 / 0 | 111,285,299 | 92 / 193 秒，最长 200 秒 | 已采区间 4 次；余 7 项阶段日志缺失 |

30 项原件创建到最终确认的有效工作窗口约一分钟；内容 session 窗口 56.91 秒，对应新文件字节/窗口 592,358 B/s。80 项完整原生状态从最早建队到最后完成 204 秒，对应 545,516 B/s，包含排队、重试，不包含用户选片之前时间，不能冒充单连接传输带宽或纯网络吞吐。

30 项 task duration P50/P95 3.752/9.166 秒，建队到 task 开始 25.999/55.079 秒，发送 1.399/2.494 秒，响应等待 2.155/3.545 秒。80 项已采交易发送 P50/P95 1.487/7.942 秒、响应等待 2.171/4.183 秒。响应等待含 Worker、Telegram 和 ACK，不能继续拆分成各服务处理时间。

HTTP0/-1017 已真机复现，发生在没有可用 HTTP 响应时，部分任务已发送全文件，部分只发送一部分；不是收到 ACK 后绑定校验失败。30 项有 3 次完整重传，重试文件共 3,093,910 B；80 项已采到 4 次完整重传，重试文件共 4,509,777 B。不能把原始 attempts=2 全部解释为一次内容重传，因为 reservation 同样递增计数。保留严格 ACK，不把“字节已发出”当作“已持久化”。

80 项最初 180 秒采样只记录 73 个 committed，之后通过现有账号保护的原生 listJobs 只读核对同批次：80 done、零去重、111,285,299 B、264 quarantined。前 73 项日志均 originalPresent=0；未对后 7 项伪造文件系统读取或阶段指标。没有用大量生产查询补证据。

## 离线、VPN、锁屏和恢复限制

飞行模式打开、Wi-Fi 关闭后，另一个 3 项批次本机 3/3、云端 0/3，原生快照证实 3 项仍保留。恢复网络后先完成 2 项去重，剩余 613,003 B 文件复现 -1017，随后最终 HTTP201/严格确认、3/3 完成，原件在确认后释放。

该文件建队到完成 2,156 秒，包含人为离线、后台停留及重试。最后一次 task interval 59.027 秒，发送 1.017 秒、响应等待 3.937 秒，fetchOffset 52.622 秒；回调在重新进入 App 的边界送达。不能把 callback 到达时刻当作真实传输结束时刻，也不能推断 iOS 无限后台执行。没有足够信息准确分离全部离线等待、系统延迟及回调滞留。

执行了 VPN 断开及恢复，确认 OFF 的状态后原任务最终完成；单次对照且窗口不连续，不足以证明 VPN 是根因。原 Wi-Fi、飞行模式 OFF、VPN 已连接已恢复，没有更改配置或路由规则。

最终只读源码复核确认现有上传仍持久化任务归属、使用有限并发的文件上传、保存失败状态后走已有重试，成功仍要求严格 ACK。当前失败分类为传输错误及后台时序待取证，尚不能证明某个项目代码缺陷。进一步区分需要同一失败 task 的调度、transaction、终止回调和重试身份时间线，与同期网络/VPN 状态对齐；不能仅凭最终成功或一次 VPN 切换归因，也没有据此修改调度与超时。

用户确认锁屏后，手机 OCR 空白；有限 60 秒锁屏采样没有新回调。解锁后 80/80 已完成，但不能确定哪些完成发生在锁屏区间，因此锁屏持续传输能力尚未通过本次独立验证。
